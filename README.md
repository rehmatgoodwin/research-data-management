# research-data-management
This repository provides templates and guidance on organisation of research data. The template aligns with FAIR (finable, accessible, interoperable and reusable) principles.



## Quick Start ##
1. Download templates from metadata-templates folder (.xls format should be compatible with excel, google sheets, LibreOffice, etc.)
2. Check metadata-templates options for ReadMe.txt templates for relevant experimental metadata conventions (i.e. AFM, UV-Visible absorption, photoluminescence, etc.) 
3. Read through docs for guidance on naming conventions, structuring characterisation folders, and organising experimental metadata
4. Check examples for examples of project organisation.

## Repository structure ##
Within this repository there are examples of folder structures for various experimental techniques (primarily atomic force microscopy).
1. Sample metadata template: an example of how to organise sample metadata, including processing conditions and selection of different characterisation done on each sample.
2. An example ReadMe.txt template for atomic force microscopy, kelvin probe force microscopy and photoluminescence quantum yield is also included.
3. An example of structuring research data for a project can be found in the examples folder. This includes a ReadMe_ExperimentGuide.txt which demonstrates how data can be managed for larger projects (i.e. articles or thesis chapters).

## Incorporating FAIR (findable, accessible, interoperable, reusable) principles ##
The following article goes through FAIR principles and it's importance in scientific research: https://www.nature.com/articles/sdata201618

FAIR stands for: 
F - findable: Clearly indexed metadata that is consistent and unique to the sample/experiment
A - accessible: Metadata is retrievable with ease using formats that are easily accessible, as well as easy to authenticate.
I - interoperable: Metadata is easily understandable, with language that is broadly understood by the research community. 
R - reusable: Description of metadata meets community standards, with detailed descriptions, allowing the community to reproduce techniques and methods easily.
